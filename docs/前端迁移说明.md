# QuantDesk 前端迁移说明

## 当前结论

`web/` 的 React + TypeScript 前端以旧版终端为像素级基准，而不是重新设计。登录、应用外壳、工作台、设置与订单页复刻原 DOM/CSS；监控、模拟、实盘、策略和回测挂载原版 Web Components，并由 React 会话层提供认证 API 桥接。React 验收入口仍为 `/next/`。

## 能力覆盖

| 业务域 | React 入口 | 已接入能力 |
|---|---|---|
| 工作台 | `#/overview` | 会话、服务/数据库健康、账户安全状态与业务入口 |
| 市场监控 | `#/monitor` | 市场概览、宽度、观察列表、机会、新闻、告警、标的证据、预测配置与历史 |
| 策略中心 | `#/strategies` | 模板/组合创建、参数版本、验证、归档、Revision、信号、部署、AI Preview/Apply |
| 回测实验室 | `#/backtest` | 目录、运行配置、历史、结果指标、数据质量、成交与完整证据 |
| 模拟交易 | `#/paper` | 账户创建、策略绑定、仪表盘、持仓、成交、权益、暂停、重置、归档 |
| 实盘控制台 | `#/live` | 账户创建、策略/风控快照、Arm 显式确认、暂停、归档、交易所与执行证据 |
| 系统设置 | `#/settings` | Binance 凭证/账户/订单、AI 模型配置 CRUD 与连通性测试 |
| 独立管理后台 | `/admin` | 保持原版独立认证、独立 UI 与管理员权限边界 |

## 部署形态

```text
FastAPI
├── /api/v2/*        共享 API
├── /assets/*        原版样式与兼容 Web Components
└── /next/*          React 会话、路由与复刻页面
```

Hash 路由不要求服务端增加页面回退。`/assets/*` 中的原版组件当前属于兼容运行时，删除前必须先完成等价 React 重写。

## 切换门槛

1. 使用普通用户和管理员分别完成所有导航、空态、错误态和写操作验收。
2. 对策略创建/编辑、回测、模拟盘和实盘控制执行新旧结果对照。
3. 在非生产资金账户验证 Arm、暂停、归档、凭证删除和管理清理的二次确认。
4. CI 通过 OpenAPI 快照、ESLint、TypeScript strict 和 Vite 生产构建。
5. 根入口切换后保留旧入口至少一个发布周期，再根据运行日志决定是否删除。

## 安全不变量

- Access Token 只保存在内存；刷新凭证使用 HttpOnly Cookie。
- 用户身份变化时立即清理前端会话，不跨标签页复用另一用户的数据。
- 管理页面的可见性不是授权边界，所有权限仍由服务端校验。
- 资金操作只提交意图；Preflight、风险限制、幂等、审计和最终执行均由服务端裁决。
- Arm 必须输入账户全名并显式确认真实资金风险。
- 清理、归档、重置和凭证删除保留明确的破坏性操作确认。

## OpenAPI 契约

后端通过 `scripts/export_openapi.py` 生成 `web/openapi.json`，前端通过 `openapi-typescript` 生成 `web/src/api/schema.d.ts`。运行 `npm run check` 会依次校验契约快照、Lint、严格类型和生产构建。

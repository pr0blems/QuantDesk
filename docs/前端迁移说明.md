# QuantDesk 前端迁移说明

## 当前结论

QuantDesk 主站已使用单一前端源码树 `web/`。React 负责认证、导航、路由和页面生命周期，现有六个复杂业务页面控制器也随 Vite 一起构建，不再由 Python 后端目录提供独立脚本。

本次迁移不重新设计 UI。当前线上 DOM、CSS、文案、布局与交互仍是唯一验收基线。

## 能力覆盖

| 业务域 | 正式路径 | 实现 |
|---|---|---|
| 工作台 | `/overview` | React 页面 |
| 合约监控 | `/monitor` | React 宿主 + 构建内页面控制器 |
| 发现机会 | `/ai-monitor` | React 宿主 + 构建内页面控制器 |
| 模拟盘 | `/paper` | React 宿主 + 构建内页面控制器 |
| 实盘交易 | `/live` | React 宿主 + 构建内页面控制器 |
| 策略中心 | `/strategies` | React 宿主 + 构建内页面控制器 |
| 数据回测 | `/backtest` | React 宿主 + 构建内页面控制器 |
| 系统设置 | `/settings` | React 页面 |
| 管理后台 | `/next/admin/` | 同一 Vite 工程输出的独立管理界面 |

## 部署形态

```text
FastAPI
├── /api/v2/*          后端 API
├── 正式页面路径        返回同一 React index.html
└── /next/*            唯一前端构建制品与静态资源
```

旧 `/assets/*.js` 页面控制器入口已经关闭。`src/quantdesk_v2/static` 已物理移除；后端只保存部署生成的 `react_static` 制品。

## UI 冻结与验收

1. 不调整颜色、字体、尺寸、间距、导航、弹窗和响应式断点。
2. 不更换页面文案、字段和按钮位置。
3. 不修改交易、回测、模拟盘或实盘的服务端判断。
4. 每次迁移必须通过源码等价检查、静态契约测试、TypeScript、ESLint、生产构建和浏览器回归。
5. 页面控制器向 React 组件的后续演进必须逐页进行；未达到视觉和交互等价前不得替换。

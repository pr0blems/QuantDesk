# QuantDesk V2 数据库字典

数据库名：`binance`。所有业务时间字段统一保存 UTC 时间。Binance API Key 与 Secret 仅保存 Fernet 密文，任何日志和接口响应均不得保存或返回明文。

## users — 平台用户及其加密后的 Binance API 凭据

| 字段 | 类型 | 空值 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | 否 | 用户主键，自增 |
| username | VARCHAR(64) | 否 | 登录用户名，全局唯一 |
| email | VARCHAR(254) | 是 | 用户邮箱，全局唯一 |
| password_hash | VARCHAR(255) | 否 | Argon2id 登录密码哈希 |
| is_active | BOOLEAN | 否 | 账户是否启用 |
| is_admin | BOOLEAN | 否 | 是否为平台管理员 |
| binance_api_key_encrypted | TEXT | 是 | Fernet 加密后的 Binance API Key |
| binance_api_secret_encrypted | TEXT | 是 | Fernet 加密后的 Binance API Secret |
| binance_key_fingerprint | VARCHAR(16) | 是 | API Key 的 SHA-256 短指纹，仅用于识别 |
| binance_key_version | INT | 否 | 凭据版本号，每次更新或删除递增 |
| binance_permissions | JSON | 是 | API 权限快照，只允许 READ 和 TRADE |
| binance_key_updated_at | DATETIME | 是 | Binance 凭据最后更新时间（UTC） |
| last_login_at | DATETIME | 是 | 最后登录时间（UTC） |
| created_at | DATETIME | 否 | 用户创建时间（UTC） |
| updated_at | DATETIME | 否 | 用户记录最后更新时间（UTC） |

索引：主键 `id`；唯一索引 `username`、`email`；普通索引 `is_active`。

## user_sessions — 用户登录会话与刷新令牌生命周期

| 字段 | 类型 | 空值 | 说明 |
| --- | --- | --- | --- |
| id | VARCHAR(36) | 否 | 会话 UUID 主键 |
| user_id | BIGINT | 否 | 所属用户 ID，外键关联 users.id |
| refresh_token_hash | VARCHAR(64) | 否 | 刷新令牌 SHA-256 哈希，不保存明文 |
| client_type | VARCHAR(16) | 否 | 客户端类型：web 或 native |
| user_agent | VARCHAR(512) | 是 | 登录客户端 User-Agent |
| ip_address | VARCHAR(45) | 是 | 登录来源 IPv4 或 IPv6 |
| expires_at | DATETIME | 否 | 刷新会话过期时间（UTC） |
| revoked_at | DATETIME | 是 | 会话撤销时间，为空表示未撤销 |
| created_at | DATETIME | 否 | 会话创建时间（UTC） |

约束：删除用户时级联删除会话；`refresh_token_hash` 全局唯一。

## audit_logs — 安全敏感操作审计日志

| 字段 | 类型 | 空值 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | 否 | 审计日志主键，自增 |
| user_id | BIGINT | 是 | 操作用户 ID，用户删除后置空 |
| action | VARCHAR(80) | 否 | 审计动作代码 |
| resource_type | VARCHAR(80) | 是 | 被操作资源类型 |
| resource_id | VARCHAR(80) | 是 | 被操作资源标识 |
| ip_address | VARCHAR(45) | 是 | 操作来源 IPv4 或 IPv6 |
| metadata_json | JSON | 是 | 脱敏后的扩展信息，禁止存放密钥和令牌 |
| created_at | DATETIME | 否 | 审计事件发生时间（UTC） |

索引：`user_id + created_at`、`action + created_at`。

## alembic_version — 数据库结构迁移版本

| 字段 | 类型 | 空值 | 说明 |
| --- | --- | --- | --- |
| version_num | VARCHAR(32) | 否 | 当前数据库结构迁移版本号，主键 |

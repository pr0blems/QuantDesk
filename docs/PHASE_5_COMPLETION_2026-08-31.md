## 1. 完成结论

第五阶段“前端单轨迁移”已经完成并部署。

正式入口现在由 React 统一负责认证、路由、页面显示、暂停、恢复和卸载。合约监控、发现机会、模拟盘、实盘交易、策略中心、数据回测六个复杂页面由 React 直接挂载页面控制器，不再通过旧 Web Component 标签作为生产宿主。

为保证用户要求的 UI 与功能完全不变，本阶段没有重写页面模板或 CSS。现有页面控制器继续使用已经在线上验证的 DOM、样式和业务交互；这是一条生产实现，不是同时维护一套新 UI 和一套旧 UI。旧自定义元素包装只保留为紧急回退兼容层。

## 2. 生产结构

```text
FastAPI 正式路由
  -> React App（唯一生产入口）
     -> 认证与 History 路由
     -> PageControllerPanel
        -> 页面控制器注册表
           -> 现有页面 DOM / CSS / API / 实时刷新逻辑
```

正式页面路径：

- `/overview`
- `/monitor`
- `/ai-monitor`
- `/paper`
- `/live`
- `/strategies`
- `/backtest`
- `/settings`

`/next/#/...` 继续作为构建部署前的灰度验证入口，不作为第二套产品页面开发。

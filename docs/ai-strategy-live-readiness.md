# AI 新闻机会策略：实盘准备优化与开发方案

版本：2026-08-11
适用模块：新闻采集、AI 新闻研判、技术指标确认、虚拟预测、预测统计、模拟盘与实盘执行

## 1. 目标与边界

目标不是承诺盈利，而是建立一条能够证明或否定策略优势的可审计链路：

1. 同一信号在研究、预测、模拟盘和实盘中使用相同的时间、价格、成本与退出口径。
2. 所有结果扣除手续费、滑点和资金成本后再判断命中。
3. 模型提示词、返回值、新闻、指标、行情和评分都保存不可变快照。
4. 未通过样本外验证前，AI 机会不得触发真实订单。
5. 实盘只允许从影子运行、模拟盘、微型实盘逐级晋升。

本方案不会将当前 AI 预测直接接入实盘。任何自动实盘接入都必须满足第 8 节准入门槛，并单独进行权限评审。

## 2. 当前基线审计

截至 2026-08-11，本地数据库中的已结算 AI 预测样本只有约 54 条，覆盖不足 20 小时：

| 项目 | 当前结果 | 结论 |
| --- | ---: | --- |
| 毛胜率 | 约 55.6% | 置信区间很宽，不能证明优势 |
| 毛平均方向收益 | 约 +10.7 bps/次 | 尚未覆盖往返交易成本 |
| 按 16 bps 往返成本估算 | 约 -5.3 bps/次 | 当前净期望为负 |
| 做多样本 | 约 32 条 | 毛平均收益为负 |
| 做空样本 | 约 22 条 | 暂时为正，但样本过小 |
| 模拟盘已完成成交 | 5 笔 | 样本不足且净收益为负 |
| 已有回测 | 多数 0～22 笔成交 | 无法作为实盘依据 |

已确认的结构问题：

- 新闻评分与技术评分的组合权重是固定的 55% / 45%，尚未经过概率校准。
- 技术指标只有布尔满足/不满足，两个指标时评分只能为 0、50、100。
- 机会记录会被后续扫描更新，历史页面可能显示的不是预测生成时评分。
- 旧预测以固定到期价格判断毛输赢，不包含真实成本、路径风险、止损和止盈。
- AI 预测模块与实盘执行模块相互隔离；这是当前必须保留的安全边界。

## 3. 目标数据链路

```text
新闻入库
  -> 去重与事件聚类
  -> AI 结构化研判（原始请求/响应留档）
  -> 候选股票与方向
  -> 市场状态与连续技术评分
  -> 成本/流动性门槛
  -> 不可变信号快照
  -> 虚拟执行（延迟、滑点、费率、资金费率）
  -> 路径结算（MAE/MFE、止损、止盈、时间退出）
  -> 成本后统计与样本外验证
  -> 影子运行
  -> 微型实盘审批
```

## 4. 第一阶段：研究口径真实化

本阶段是当前开发范围。

### 4.1 不可变信号快照

每条虚拟预测保存：

- 生成时新闻评分；
- 生成时指标评分；
- 组合评分；
- 指标逐项证据；
- 相关新闻与模型调用标识；
- 入场参考价、方向、周期和生成时间；
- 成本模型版本。

统计接口只能读取预测快照，不再读取可能被后续扫描覆盖的机会评分。

### 4.2 成本后收益

第一阶段使用保守、可追溯的默认成本模型：

- 单边手续费：5 bps；
- 单边滑点：3 bps；
- 往返基础成本：16 bps；
- 资金成本：按 1 bps / 8 小时和实际持有时长估算；
- 成本后方向收益 = 毛方向收益 - 全部估算成本。

后续接入账户真实费率、实际成交滑点、当期资金费率后替换默认值。

### 4.3 路径风险

结算时读取预测生成至到期之间的 15 分钟 K 线，计算：

- MFE：最大有利波动；
- MAE：最大不利波动；
- 毛方向收益；
- 成本后方向收益；
- 毛结果与成本后结果。

命中率、平均收益和筛选统计默认使用成本后结果，同时保留毛结果用于审计。

### 4.4 2026-08-11 实施结果

第一阶段已落地：

- 数据库迁移版本：`0045_ai_prediction_metrics`；
- 新预测保存新闻分、指标分、成本模型和结算版本的不可变快照；
- 预测结算同时保存毛收益、估算成本、净收益、净结果、MFE 和 MAE；
- 最近 60 条跨账户已结算预测已完成路径指标回填，缺失 0 条；
- 当前账户统计改为成本后口径：54 条样本，毛均值约 +10.73 bps，平均成本 16.125 bps，净均值约 -5.39 bps，成本后命中率约 37.04%；
- 预测统计页面已经区分毛收益/净收益，并显示成本与 MFE/MAE；
- AI 预测与实盘订单仍保持隔离。

这组结果进一步说明当前策略尚未达到实盘准入标准；第一阶段的价值是让负期望能够被真实看见，而不是通过毛收益或可变评分掩盖。

## 5. 第二阶段：信号质量优化

### 5.1 新闻事件层

- 对相同事件的中英文、转载和连续快讯进行聚类，避免重复加权。
- 增加新闻新颖度、来源可靠度、首次发布时间和采集延迟。
- 财报、指引、评级、并购、监管、宏观和地缘事件分别设置衰减时间。
- AI 的 `time_horizon` 必须与 15m、1h、4h 预测周期对应。
- 相关股票必须通过公司实体映射和交易品种白名单双重验证。

### 5.2 连续技术评分

技术评分从“满足数量”改为连续特征：

- 均线斜率及价格到均线距离 / ATR；
- 突破距离 / ATR；
- 成交量历史分位数；
- 盘口失衡强度；
- 波动率分位数；
- 指数与行业相对强弱；
- 跳空幅度和交易时段流动性。

做多与做空分别校准，不共享阈值。

### 5.3 交易价值门槛

只有当预测净优势满足以下条件时才生成可交易信号：

```text
预测毛优势 > 手续费 + 滑点 + 资金成本 + 安全边际
```

新闻置信度或组合评分本身不能代替预期收益。

### 5.4 2026-08-11 连续指标与准入门槛实施结果

本轮已经完成：

- K 线策略加入基于 ATR 的趋势距离、均线斜率、突破幅度、量能、动量、缺口和反转强度，输出 0～100 连续方向分；
- 预测因子把原有 `-1～1` 原始值按方向与数据质量转换成连续分；
- “所选指标全部满足”的 AND 规则继续保留，技术评分改为所选指标方向强度的平均值；
- 加入最低技术强度、最低组合评分、最大行情延迟、预测因子最低质量、校准样本数和成本安全边际配置；
- 同方向历史预测计算平均毛优势及 95% 置信区间下限，只有下限覆盖手续费、滑点、资金成本和安全边际时才可标为影子候选；
- 曾经确认但最新指标已经失效的机会会立即降级为新闻候选，不再沿用旧的确认状态；
- 预测统计页面增加 8 项准入检查，区分研究信号和影子候选。

当前账户的准入检查为 **0 / 8 通过**：54 条样本、跨度约 0.81 天、净收益 95% 下限约 -31.74 bps、成本后利润因子约 0.83、双倍成本压力平均约 -21.52 bps。因此系统保持研究阶段是正确结果。

### 5.5 可配置成本口径

预测统计页现已提供用户级持久成本配置，并默认全部启用：

- 手续费：默认单边 5 bps，完整持有周期按开、平两边扣除；
- 滑点：默认单边 3 bps，完整持有周期按开、平两边扣除；
- 资金成本：默认每 8 小时 1 bps，按实际预测持有时长折算；
- 三类成本可独立关闭或调整，保存后历史命中率、净收益、利润因子、置信下限及双倍成本压力测试均按当前配置重新计算；
- 毛收益保持不变并继续展示，便于核对成本影响；信号生成时仍冻结当时的成本假设，确保单条预测可审计。

## 6. 第三阶段：验证体系

- 建立事件时间数据集，所有特征只能使用信号时点之前可获得的数据。
- 时间滚动训练/验证/测试，最终测试集不得参与调参。
- 对重叠标签使用时间隔离，避免相邻样本泄漏。
- 记录每次参数和提示词试验，计算多重试验带来的过拟合风险。
- 分别报告月份、市场状态、品种、做多/做空和新闻类别表现。
- 使用实际成本、2 倍成本和延迟压力情景。
- 对模型置信度计算分桶胜率、Brier Score 和校准误差。

## 7. 执行与风控要求

现有实盘引擎已经具备订单意图幂等、行情新鲜度、ATR 风险仓位、保护单、每日亏损和回撤限制。正式接入前还需验证：

- 超时后订单状态未知的查询与对账；
- 部分成交、拒单、重复回调和断线重连；
- 止损/止盈保护单缺失时立即停止新开仓；
- 账户持仓与本地持仓不一致时失败关闭；
- 每品种、行业相关簇和账户总风险上限；
- 独立紧急停止开关和告警；
- 交易 API Key 禁止提现并限制来源地址；
- 每次发布均有版本、回滚和影子验证记录。

## 8. 实盘准入门槛

以下全部满足后，才允许提交微型实盘审批：

1. 至少 1,000 条已结算、去重后的预测，跨度不少于 6 个月。
2. 成本后平均收益的 95% 置信区间下限大于 0。
3. 样本外利润因子不低于 1.20。
4. 2 倍手续费和滑点压力下仍为正收益。
5. 至少 5 个时间分段为正，不能只靠一个月份、股票或方向盈利。
6. 单一股票或单日贡献不超过总利润的 20%。
7. 影子运行不少于 4 周，订单错误和裸仓保护事故为 0。
8. 同执行链模拟盘至少 100 笔，实际滑点不高于模型压力值。

微型实盘初始限制：

- 杠杆 1～2 倍；
- 单笔账户风险不超过 0.10%；
- 总开放风险不超过 0.50%；
- 最多同时 2 个仓位；
- 日亏损 0.50% 后停止开仓；
- 总回撤 2% 后自动暂停；
- 禁止摊平补仓和马丁格尔。

## 10. 验收标准

第一阶段完成后：

- 新预测必须有生成时评分字段；
- 已结算预测必须有成本、净收益和净结果；
- 有完整行情的预测必须有 MAE/MFE；
- 统计页面明确区分毛收益和成本后收益；
- 命中率默认按成本后结果计算；
- 旧记录可兼容展示，并标明回填版本；
- AI 预测仍不得产生任何真实订单。

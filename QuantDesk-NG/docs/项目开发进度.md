## 1. 总览

项目已具备“监控 → 预测 → 回测/策略 → 模拟盘 → 反馈治理”的可运行基础，并已完成代理、预测治理、权益和可观测性的一轮补强。当前完成度应按能力分层看待：

- **可运行且已验证**：账户安全、行情/监控、预测账本、新闻质量处理、策略/回测、模拟盘、迁移、健康检查与 Worker 租约。
- **已实现安全治理或接口骨架**：参数候选审批、模型证据/发布门控、Clash 节点管理、套餐配额、Prometheus 指标、外部 API v1。
- **尚未达到生产交易或商业化标准**：自动实盘、Mihomo、真实支付、真实多 LLM 并行调用与模型市场、端到端浏览器测试、生产部署演练。

## 6. 近期运行风险

1. 真实 Binance/AI/代理凭据尚未在新环境配置，相关功能会正确降级或不可用。
2. 本地 MariaDB 适合开发和私人部署；生产需完成备份、恢复、TLS、监控告警和容量演练。
3. 新闻、预测和美股数据的供应商可用性受网络与 API 限额影响，需通过质量标签而非“永远在线”的假设处理。
4. GitHub 合并后的工作流检查需要继续观察；远端 CI 的成功与本地全量测试应分别记录。

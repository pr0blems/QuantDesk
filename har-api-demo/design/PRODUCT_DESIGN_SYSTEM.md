# 知势 Pulse 产品样例设计系统

## 产品结构

- 顶部：品牌、市场导航、全局搜索、离线状态和接口目录入口。
- 主工作区：自选列表 / 证券行情与分时图 / AI 速览三栏。
- 数据带：订单簿、分时成交、新闻、社区情绪和 IPO 关注。
- 核心交互：证券切换、周期切换、搜索、新闻收藏、洞察折叠和数据带跳转。

## 视觉令牌

- 背景：`#080d10`
- 面板：`#10171b`
- 抬升面板：`#151d22`
- 边框：`#2b363d`
- 主文字：`#f3f5f4`
- 次文字：`#95a0a6`
- 强调色：`#9be532`
- 下跌色：`#ff5b57`
- 上涨色：`#75d84b`
- 圆角：6px / 8px
- 字体：Inter、PingFang SC、Microsoft YaHei；数字使用 SFMono / Consolas。

## 组件规则

- 面板采用开放式轨道和细边框，不做漂浮卡片或大面积阴影。
- 行情数字使用等宽数字，主价格 46–52px，控制文本 12–14px。
- 选中态使用左侧 3px 荧光绿轨道或底部 2px 指示线。
- 图表以珊瑚红折线和轻透明面积表达下跌，成交量保持低饱和红/绿。
- 移动端按“行情头部 → 图表 → AI 速览 → 数据模块”顺序纵向展开。
